---
title: Composables
description: Référence des composables Syora, Vue Router, Unhead et Schema.org auto-importés.
---

Les composables sont disponibles sans import dans les composants, pages, layouts, middlewares et plugins analysés par Syora.

| Domaine | API |
| --- | --- |
| Données | `useAsyncData`, `useFetch` |
| Configuration | `useConfig`, `useRuntime` |
| Application | `useApp`, `useAppError` |
| Navigation | `useRouter`, `useRoute`, `navigateTo`, `onBeforeRouteUpdate` |
| Head | `injectHead`, `useHead`, `useSeoMeta`, `useHeadSafe` |
| Données structurées | `useSchemaOrg` |
