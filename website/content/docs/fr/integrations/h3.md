---
title: h3
description: Reliez manuellement h3 à Syora avec les primitives Node ou Fetch API.
---

Syora ne fournit pas encore de fonction `h3()` dédiée. Utilisez les primitives bas niveau dans un handler catch-all.

```ts
import { createSyoraApp, requestNode } from "@syora/core";

const syoraApp = createSyoraApp();

export default defineEventHandler(async (event) => {
  await requestNode({
    syoraApp: await syoraApp,
    req: event.node.req,
    res: event.node.res,
  });
});
```

Cet exemple correspond aux versions de h3 qui exposent `event.node.req` et `event.node.res`. Si votre runtime fournit une `Request` standard, utilisez `requestWeb()` et retournez sa `Response`.

Montez ce handler après vos routes API.
