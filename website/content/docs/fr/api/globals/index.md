---
title: Globals
description: Référence des fonctions globales injectées automatiquement par Runable.
---

Runable rend plusieurs fonctions disponibles sans import manuel.

| API | Rôle |
| --- | --- |
| `$fetch` | Effectuer une requête HTTP avec ofetch |
| `definePageMeta` | Déclarer les métadonnées d'une page |
| `defineVueMiddleware` | Définir un ou plusieurs guards de navigation |
| `defineVuePlugin` | Déclarer un plugin applicatif Runable |
| Vue APIs | Utiliser les exports courants de Vue sans import |
