---
title: h3
description: Connect h3 to Syora manually with the Node or Fetch API primitives.
---

Syora does not yet provide a dedicated `h3()` function. Use the low-level primitives in a catch-all handler.

```ts
import { createSyoraApp, requestNode } from "@syora/core";

const syoraApp = createSyoraApp();

export default defineEventHandler(async (event) => {
  await requestNode({
    syoraApp: await syoraApp,
    req: event.node.req,
    res: event.node.res,
  });
});
```

This example targets h3 versions that expose `event.node.req` and `event.node.res`. If your runtime provides a standard `Request`, use `requestWeb()` and return its `Response`.

Mount this handler after your API routes.
